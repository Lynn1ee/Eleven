# 业务数据登记与报表系统

## 概述

接收飞书用户消息，自动识别消息类型并登记到飞书多维表格（lark-base），支持查询统计、修改删除、定时提醒，以及自动生成含可视化图表的日报/周报/月报。

## 数据表结构

每月在同一个 Base 中创建两张表。Base 名称：`业务数据登记_YYYY-MM`。

### 表1：IM会话量(拼多多+千牛+抖音)

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期 | 日期 | 登记日期，默认当天 |
| 姓名 | 文本 | 发送人姓名，从飞书消息自动获取 |
| 拼多多火车票 | 数字 | 拼多多-火车票会话量 |
| 拼多多机票 | 数字 | 拼多多-机票会话量 |
| 千牛 | 数字 | 千牛平台会话量 |
| 抖音 | 数字 | 抖音平台会话量 |
| 合计 | 数字 | 拼多多火车票 + 拼多多机票 + 千牛 + 抖音，自动计算 |
| 备注 | 文本 | 可选备注信息 |

### 表2：火车票分销群聊登记表

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期 | 日期 | 登记日期，默认当天 |
| 姓名 | 文本 | 发送人姓名，从飞书消息自动获取 |
| 订单号 | 文本 | 订单编号 |
| 备注 | 文本 | 可选备注信息 |

详细建表 Schema 见 `references/table-schemas.md`。

## 消息分类与处理

收到消息后，按以下规则自动判断：

1. **包含订单号格式**（如 HT 开头、纯数字编号等） → 写入 **表2**，多个订单号用逗号/空格/换行分隔时，逐个拆分为多条记录
2. **包含平台关键词+数字**（拼多多火车票/拼多多机票/千牛/抖音 后跟数字） → 写入 **表1**，自动计算合计
3. **查询类**（包含"查询""统计""汇总""多少"等） → 执行查询统计
4. **修改/删除类**（包含"修改""改一下""删除""删掉"等） → 执行修改或删除
5. **报表类**（包含"日报""周报""月报""报表"等） → 生成对应报表
6. **提醒类**（包含"提醒""催一下"等） → 发送提醒消息

### 登记示例

```
用户发送: 拼多多火车票5000，拼多多机票2000，千牛3000，抖音2000
→ 表1写入1条: {日期: 今天, 姓名: 自动获取, 拼多多火车票: 5000, 拼多多机票: 2000, 千牛: 3000, 抖音: 2000, 合计: 12000}

用户发送: HT001, HT002, HT003
→ 表2写入3条: 每条 {日期: 今天, 姓名: 自动获取, 订单号: HT00X}

用户发送: HT001 HT002 HT003
→ 同上，空格分隔也支持

用户发送: HT001
→ 表2写入1条
```

## 工作流

### 1. 数据登记

1. 从飞书消息上下文获取发送人姓名（`lark-im` 获取 sender 信息）
2. 根据消息内容判断写入表1还是表2
3. 提取数据字段：
   - 表1：正则匹配 `拼多多火车票\d+` `拼多多机票\d+` `千牛\d+` `抖音\d+`，计算合计
   - 表2：提取所有订单号，批量拆分
4. 检查当月 Base 和对应表是否存在，不存在则自动创建
5. 写入数据，返回确认消息

### 2. 查询统计

支持以下查询类型：
- 按人查询：某人的历史数据汇总
- 按平台查询：拼多多/千牛/抖音的累计值
- 按时间查询：某天/某周/某月的数据
- 排名查询：按合计/订单数排名

### 3. 修改与删除

1. 先查询定位目标记录
2. 展示匹配结果，让用户确认
3. 执行修改或删除操作
4. 返回操作结果

### 4. 定时提醒

两个班次下班前 5 分钟自动发送提醒到飞书群：
- 白班：每天 14:55
- 晚班：每天 23:55

### 5. 月度建表

每月1号（由飞书自动化触发）：
1. 检查当月 Base 是否已存在
2. 不存在则创建新 Base 并建立两张表
3. 发送确认消息

### 6. 报表生成

报表模板和可视化规范见 `references/report-templates.md`，分析方法见 `references/analysis-methods.md`。

#### 日报（次日生成）
- 当日两张表的数据汇总
- 对比昨日环比涨跌
- 折线图：近7天趋势

#### 周报（次周第一天生成）
- 当周数据汇总 + 人员排名柱状图
- 平台占比饼图（拼多多火车票/拼多多机票/千牛/抖音）
- 日趋势折线图
- 表2订单量统计

#### 月报（次月第一天生成）
- 全月数据汇总
- 四维分析：人员排名对比、平台占比分析、环比涨跌趋势、异常数据预警
- 可视化图表（参考 `scripts/chart_gen.py`）
