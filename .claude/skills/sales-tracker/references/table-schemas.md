# 飞书多维表格建表 Schema

## Base 结构

每月一个 Base，命名格式：`业务数据登记_YYYY-MM`（如 `业务数据登记_2026-05`）。

Base 内包含两张表。

---

## 表1：IM会话量(拼多多+千牛+抖音)

### 字段定义

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 日期 | 日期 | 是 | 默认当天，格式 YYYY-MM-DD |
| 姓名 | 文本 | 是 | 从飞书消息发送人自动获取 |
| 拼多多火车票 | 数字 | 否 | 整数，拼多多-火车票会话量，默认 0 |
| 拼多多机票 | 数字 | 否 | 整数，拼多多-机票会话量，默认 0 |
| 千牛 | 数字 | 否 | 整数，千牛平台会话量，默认 0 |
| 抖音 | 数字 | 否 | 整数，抖音平台会话量，默认 0 |
| 合计 | 数字 | 是 | 拼多多火车票 + 拼多多机票 + 千牛 + 抖音，自动计算 |
| 备注 | 文本 | 否 | 备注信息 |

### 建表 API 参数（lark-base）

```json
{
  "table_name": "IM会话量(拼多多+千牛+抖音)",
  "fields": [
    {"field_name": "日期", "type": 5},
    {"field_name": "姓名", "type": 1},
    {"field_name": "拼多多火车票", "type": 2},
    {"field_name": "拼多多机票", "type": 2},
    {"field_name": "千牛", "type": 2},
    {"field_name": "抖音", "type": 2},
    {"field_name": "合计", "type": 2},
    {"field_name": "备注", "type": 1}
  ]
}
```

> 字段类型编号: 1=文本, 2=数字, 5=日期

---

## 表2：火车票分销群聊登记表

### 字段定义

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 日期 | 日期 | 是 | 默认当天，格式 YYYY-MM-DD |
| 姓名 | 文本 | 是 | 从飞书消息发送人自动获取 |
| 订单号 | 文本 | 是 | 订单编号，支持批量（逗号/空格分隔时拆分） |
| 备注 | 文本 | 否 | 备注信息 |

### 建表 API 参数（lark-base）

```json
{
  "table_name": "火车票分销群聊登记表",
  "fields": [
    {"field_name": "日期", "type": 5},
    {"field_name": "姓名", "type": 1},
    {"field_name": "订单号", "type": 1},
    {"field_name": "备注", "type": 1}
  ]
}
```

---

## 月度建表流程

每月1号由飞书自动化触发：

1. 调用 `lark-base` 创建 Base，名称 `业务数据登记_YYYY-MM`
2. 在 Base 中创建表1和表2
3. 发送确认消息到群："✅ 本月数据表已就绪：`业务数据登记_YYYY-MM`"

如果当月 Base 已存在则跳过，避免重复创建。
