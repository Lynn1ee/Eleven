# 元气工作站（Admin Automation）项目开发报告

> 报告周期：2026年5月24日 — 2026年6月30日

---

## 一、项目概述

元气工作站是一套面向客服团队管理的内部自动化工具平台，涵盖数据排名与预警、满意度激励、任务量统计、月考成绩管理、发票报销汇总等核心业务场景。系统采用前后端一体化架构，通过浏览器即可访问，支持多人协作。

**访问方式**：`https://localhost:8899/`（HTTPS）或 `http://局域网IP:8898/`（HTTP）

---

## 二、技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 后端 | Python 3.12 + http.server | 内置库实现多线程 HTTP/HTTPS 服务器 |
| 前端 | 原生 HTML/CSS/JS（单文件） | 无框架依赖 |

## 三、功能模块

### 1. 客服日览数据排名及预警

- 导入每日客服数据 XLSX，自动解析 10 项核心指标（签入时长、小休、午休、会话数、打赏积分、评价率、满意度、平均会话时长、首次回复、在线工作率）
- 生成摘要统计卡片（总会话数、总打赏积分、平均会话时长、平均评价率、平均不满意率）
- 四项指标 TOP 3 排名面板
- 自定义预警基准值，低于/高于基准自动标记预警，红色高亮
- 联合预警规则（小休+午休合计 ≤1.5h 不单独预警）
- 一键复制日报为图片，可直接粘贴到聊天或文档
- 支持排除人员名单（实习/请假人员不参与统计）

### 2. 满意度激励排名

- 上传本月/上月评价率数据，自动计算进步率
- 按进步率排名，前 10 名进入激励范围并标记"激励"徽章
- 评价率门槛机制（默认 ≥30%），未达标者折叠展示
- 可视化进度条（正向绿色、正向未激励紫色、负向红色）
- 一键复制排名报表为图片、导出为 PNG
- 支持排除人员名单
- 排名数据持久化，刷新页面不丢失
- 报表日期展示（前一天数据日期）

### 3. 月度任务量统计

- 上传 3 个数据源（在线会话量、机票/火车票分销明细、飞书业务任务量导出表）
- 自动合并计算各员工当月会话总量、在线时长、折算任务量
- 支持员工姓名映射（花名 ↔ 真实姓名）
- 分组管理（客服组/分销组/自定义分组）
- 自定义标准工时，自动计算任务量占比
- 导出格式化的 Excel 统计表
- 历史数据查看（按月切换）

### 4. 月考成绩统计

- 导入在线客服月考成绩 XLSX
- 自动计算排名（平均分、首次通过率）
- 打字测试截图管理（支持粘贴/拖拽上传）
- 导出格式化 Excel 成绩单
- 导出 Word 成绩报告（含打字截图嵌入）
- 历史月份数据查看与对比

### 5. 发票报销汇总系统

- 管理员创建报销周期，自动生成员工上传链接
- 员工端独立上传页面（无需登录），选择周期后上传发票 PDF
- PDF 自动解析：发票号码（20位）、姓名、金额、开票日期
- 三引擎 PDF 文本提取（pdfplumber → PyMuPDF → PyPDF2），自动适配不同发票格式
- 支持中国电信、中国移动、中国联通等运营商电子发票
- 金额自动计算（每人每月 ≤100 元，超出按 100 元计）
- 验真流程：员工上传税务局验真截图（支持 Ctrl+V 粘贴）
- 验真状态自动判定
- 一键导出：Excel 汇总表 + 结构化文件夹（PDF/ + PDF+验真/姓名/）
- 文件自动命名（姓名+发票号.pdf）

### 6. 邮件系统

- 邮件模板管理（新增/编辑/删除），支持 HTML 正文
- 模板中动态变量替换
- SMTP 配置管理（支持 163/Gmail/企业邮箱）
- 批量发送 + 抄送（全局默认 CC 自动合并去重）
- 发送历史追踪（成功/失败状态）
- 邮件内容加密存储

### 7. 系统基础设施

- 用户登录/登出认证
- 双端口 HTTP（8898）+ HTTPS（8899）同时服务
- 进程守护（watchdog），崩溃自动重启
- Windows 开机自启（VBS 脚本）
- 全局共享数据缓存 + 30 秒轮询同步（多人协作）
- 静态文件本地托管
- 工作日/节假日工时计算

## 五、技术要点

1. **零框架依赖**：前端纯原生 JS，后端仅用 Python 标准库 + 少量第三方库（PDF 解析、Excel 生成）
2. **多 PDF 引擎自适应**：发票上传模块使用 pdfplumber / PyMuPDF / PyPDF2 三个工具同时提取文本，自动选用能正确识别姓名的结果，适配不同格式的电子发票
3. **图片复制到剪贴板**：日报和排名报表通过 html2canvas 渲染为图片后写入系统剪贴板，可直接粘贴到飞书/微信
4. **单文件前端**：管理后台所有功能（5 个业务模块 + 邮件系统）整合在一个 HTML 文件中，通过面板切换实现零跳转体验
5. **进程高可用**：watchdog 守护进程监控 HTTP/HTTPS 双端口，异常退出自动重启，配合 Windows VBS 脚本实现开机自启
6. **数据安全**：邮件密码等敏感信息使用 Fernet 对称加密存储，SMTP 连接强制 TLS
