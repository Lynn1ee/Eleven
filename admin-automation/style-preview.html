📐 统计规则

📌 分 三个组别：专职分销 / 专职大夜 / 在线客服
📌 合计 = 在线会话量 + 机票分销 + 火车票分销 + IM会话 + 外部支援 + 带教/支援
📌 当月分值 = (合计 ÷ 本组最高合计) × 20
📌 专职大夜不计算当月分值
📌 按 合计降序 排列
📌 外部支援 / 带教计算：
  各组基准值 = 本组(在线/分销)会话量 ÷ 标准工时 ÷ 本组人数
  外部支援 = 基准值 × 支援小时数
