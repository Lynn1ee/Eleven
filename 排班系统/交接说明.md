# 在线客服排班系统 — 交接说明

## 一、这是什么

一个 **Python 自动化排班引擎**，替代之前网页版手工排班工具。

- 用历史进线量数据推算每天需要多少人
- 算法自动分配 23 人在线轮转（谁哪天上班/休息/什么班次）
- 一键输出带格式的 Excel，打开即用

**与旧网页版的核心区别：**

| | 旧网页版 | 新脚本 |
|------|----------|--------|
| 排班方式 | 手工拖拽 | 算法自动 |
| 耗时 | 小时级 | 分钟级 |
| 人力依据 | 凭经验 | 数据驱动（进线量系数） |
| 约束检查 | 人工目测 | 自动验证 |
| 适配新月 | 重新做 | 改 5 个参数 |

## 四、适配新月份 — 只需要改这几处

打开 `generate_schedule.py`，找到开头配置区，改 5 个参数：

```python

YEAR = 2026
MONTH = 8          # 改成目标月份
NUM_DAYS = 31       # 8月31天
START_WEEKDAY = 6   # 8月1日是周六（0=周一, 6=周日）

# 2. 人员名单（如果有人离职/入职，改这里）

# 3. 输出文件路径（自动生成到脚本同目录）

# 4. 每日目标人数（参考7月逻辑说明.md的公式重算）
DAILY_TARGETS = [...]  # 每月重新推算
```

## 五、算法做了什么

排班分 **5 组** 按顺序生成，完成后合并输出：

| 步骤 | 组 | 人数 | 规则 |
|------|-----|------|------|
| 1 | 班长 | 3人 | 何丹妮工作行政/周末休；曾瑾李玲长白班上2休2交替 |
| 2 | 专职分销 | 3人 | 3人轮转上4休2，早早IM/晚一IM/机动三种角色公平分配 |
| 3 | 专职夜班 | 4人 | B组A组上2休2交替，31天B组16天/A组15天 |
| 4 | 行政班 | 1人 | 舒丹工作日行政班/周末休 |
| 5 | **在线轮转** | 23人 | 7阶段优化（见下） |

**在线轮转 7 阶段算法：**

```
贪心初始 → 断长连 → 修休数 → 推休到月末
    → 目标匹配 → SA微调 → 迭代断连 → 分班次
```

关键约束：每人8休 / 连上 ≤5天 / 连休 ≤2天 / 零连上≥6天 / 每日人数匹配目标

## 八、常见问题

**Q: 人员变动了怎么办？**  
改 Python 脚本里的 `online_staff` 列表，增删人员即可。

**Q: 目标人数怎么算？**  
详见 `7月排班逻辑说明.md` 第二章。核心公式：去年同月进线量周系数 × 日系数 → 分配比例 → 每日目标。

**Q: 输出 Excel 打不开？**  
脚本有 3 级回退保存机制（原路径→_new→_v2→时间戳），通常是被 Excel 锁住了，关掉 Excel 重跑。

**Q: 想调整某个人的排班？**  
直接跑完脚本后在 Excel 里手动微调，公式会自动更新统计数字。

**Q: 脚本报错怎么办？**  
检查 Python 是否已安装、openpyxl 库是否已安装（`pip install openpyxl`）。把报错信息发给开发者。
