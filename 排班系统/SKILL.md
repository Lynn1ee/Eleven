# 在线客服月度排班表生成

## 触发条件

用户提到以下任一关键词时启动：
- "排班"、"/排班"、"排班表"、"班表"
- "生成排班"、"X月排班"
- "下个月排班"

## 核心职责

自动完成以下全流程：
1. 根据目标月份调整参数（年份、月份、天数、星期）
2. 按五组规则生成排班：班长 → 专职分销 → 专职夜班 → 行政班 → 在线
3. 多阶段算法优化在线排班（贪心→断连→修休→目标匹配→SA→分班次）
4. 输出带 COUNTIF 公式和格式的 Excel 文件

## 排班规则

### Step 1: 班长（3行）

- **何丹妮**: 工作日→行政班, 周末→休（23行政+8休=184h）
- **曾瑾**: 长白班上2休2, 从7/1开始: `(day-1)%4 in [0,1]`（16长白+15休=184h）
- **李玲**: 长白班上2休2, 从7/3开始: `(day-3)%4 in [0,1]`, **加 day=1 补1天**（16长白+15休=184h）

> 注意：31天奇数月时，后启动方（李玲）天然少1天。补 day=1 解决。30天月可能不需要补。28天2月需重新计算。

### Step 2: 专职分销（3行）

- 3人轮换, 上4休2, 每人8休23上班
- 6天周期, offset=[0,2,4], 从6/30状态顺延
- 每日1早早IM + 1晚一IM, 第3人休或白班机动
- **角色分配**: 计数器均衡法
  - 2人在岗(1人休): 早早IM给zao_im_cnt少者, 晚一IM给另一人
  - 3人在岗: 机动用 `(day%3)` 旋转破平 + `jidong_cnt` 取少者
  - 早早IM/晚一IM用 `zao_im_cnt`/`wan_im_cnt` 取少者
- **晚接早约束**: 晚一IM次日不接早早IM

### Step 3: 专职夜班（4行）

- B组(王颖+王欣怡)先上, A组(张玉婕+魏溪)休息
- 上2休2交替: `block = (day-1)//2`, B组 block%2==0→大夜, A组反之
- 31天月: B组16天, A组15天

### Step 4: 行政班（1行）

- 舒丹, C列标"在线"
- 工作日行政班, 周末休
- 计入在线人力统计

### Step 5: 在线 — 多阶段算法

> DAILY_TARGETS 只覆盖轮转人员，不含行政班固定人员。

**DAILY_TARGETS**: 按当月工作日/周末分布设定，总和=轮转人数×工作日天数
参考7月值(25人轮转): W1=[18,17,17,16,16] W2=[17,16,17,17,17,13,15] W3=[18,19,19,21,20,16,18] W4=[19,20,20,22,21,17,19] W5=[22,22,22,22,22]

**Phase 1 — 贪心前向**: 每天优先选休息最少的人上班, 渐进取 cap=target+2, 周末平等轮休
**Phase 1.5 — 断长连**: 单轮扫所有≥5天连上, 在W1-W4找可牺牲休息日（连休≤2），W5 max_allowed=6
**Phase 2 — 修休数**: 多休者删休（max_extra: W5=1, W1-W4=2, 优先去W5）
**Phase 2.5 — 推休到W5**: W1-W4多余休→W5（last_rest≤25→把早期休挪到W5）
**Phase 3 — 目标匹配**: 超目标日移休到缺人日, 保证maxWork≤5/maxRest≤2
**Phase 4 — SA微调**: 模拟退火, only_improve, 约束maxWork≤5
**Phase 4.6 — 迭代断连**: 最多50轮, 从连上≥6中间抽1天改休→在W1-W4找休改上班（不产生新连上≥6, 每日目标差≤±3）
**Phase 5 — 最终修休**: 确保每人8休
**Phase 6 — 分班次**: 每日按base_shifts比例分配, 白班机动公平计数器(`jd_count`), 晚二公平计数器+后交换

**关键约束**: maxWork≤5, maxRest≤2, 无连上≥6

## Excel 输出格式

### 结构（固定列）

| 列 | 内容 |
|----|------|
| A | 序号 |
| B | 工号 |
| C | 组别标签（班长/专职分销/专职大夜/在线） |
| D-AH | 31天日期（D1=7/1 ... AH1=7/31） |
| AI-AU | 个人统计 COUNTIF 公式 |
| Row 44-53 | 统计组一：在线常规班次 COUNTIF |
| Row 55-58 | 统计组二：分销IM班次 COUNTIF |

### 日期表头（Row 1, D-AH）

- 值为 `datetime` 对象, 数字格式 `m/d;@`
- **周六/周日** 字体红色 (FFFF0000), 周一至周五黑色 (FF000000)
- bold=True, size=8, 居中+自动换行

### 表头班次标签（Row 1, AI-AU）

```
AI1: 休 | AJ1: 行政班 | AK1: 白班\n(机动) | AL1: 晚二 | AM1: 早早班
AN1: 早班 | AO1: 早三 | AP1: 白班 | AQ1: 中三 | AR1: 中四
AS1: 晚一 | AT1: 晚二 | AU1: 大夜
```
- bold, size=8, 居中+自动换行, 字体黑色

### 每人员工统计公式（AI-AU 列）

```
AI: =COUNTIF(D{row}:AH{row},"休")+COUNTIF(D{row}:AH{row},"请假")
AJ: =COUNTIF(E{row}:AH{row},"行政班")   # 从E列开始（7/2起统计）
AK: =COUNTIF(E{row}:AH{row},"白班\n(机动)")
AL: =COUNTIF(E{row}:AH{row},"晚二")
AM: =COUNTIF(D{row}:AH{row},"早早班\n(IM)")
AN: =COUNTIF(D{row}:AH{row},"早班")
AO: =COUNTIF(D{row}:AH{row},"早三")
AP: =COUNTIF(D{row}:AH{row},"白班")
AQ: =COUNTIF(D{row}:AH{row},"中三")
AR: =COUNTIF(D{row}:AH{row},"中四")
AS: =COUNTIF(D{row}:AH{row},"晚一")+COUNTIF(D{row}:AH{row},"晚一\n(IM)")
AT: =COUNTIF(D{row}:AH{row},"晚二")
AU: =COUNTIF(D{row}:AH{row},"大夜")   # 公式非硬编码0
```

### 底部统计 (Rows 44-58)

统计范围: `D{fx_start_row}:AH{online_end_row}`（分销首行到在线末行）

**组一 (Row 44-53, 在线常规)**:
早班/早三/行政班/白班/中三/中四/晚一/晚二 各一行 COUNTIF
大夜: `=COUNTIF(D{night_start}:D{online_end},"大夜")`（从夜班首行开始）
合计: `=SUM(D44:D51)`（不含大夜）

**组二 (Row 55-58, 分销IM)**:
Row 55: 早早IM, Row 56: 晚一IM, Row 57: 白班机动
合计: `=SUM(D55:D57)`

- 所有数据单元格: size=8, 水平居中+垂直居中+自动换行
- 列宽: 统一为 6
- **休** 填充色: FFFFC000（深黄色）

- **白班(机动)** 填充色: FFEE822F（橙色）

## 验证标准

生成后必须检查：

1. **在线**: 每人8休, maxWork≤5, maxRest≤2, 零连上≥6
2. **分销**: 早早IM/晚一IM 三人差异≤3, 机动差异≤1, 晚接早≈0
3. **班长工时**: 何丹妮184h(23行政), 曾瑾184h(16长白), 李玲184h(16长白)
4. **夜班**: B组16天/A组15天(31天月), 两组上2休2交替
5. **行政班**: 工作日行政班, 周末休
6. **每日人数**: 总在岗=a+b, a=在线25人+分销3人+夜班2人+长白1人=31, b=行政班1人(工作日)+机动, 对比DAILY_TARGETS

## 适配新月份

生成新月排班时只需要修改：

1. **配置区**: `JULY_YEAR`, `JULY_MONTH`, `NUM_DAYS`, `JULY_1_WEEKDAY`
2. **DAILY_TARGETS**: 按26人(25轮转+1行政班)×工作日天数=月总人次，减去行政班固定出勤得到25轮转人员日目标（公式见Step 5）
3. **周末日期列表**: 用于红色字体（自动从weekday计算）
4. **分销offset**: 从上月最后一天状态顺延
5. **夜班起始组**: 从上月最后一天状态顺延（上2休2哪组先上）
6. **李玲补天**: 奇数月加 day=1, 偶数月可能需要调整
7. **输出路径**: 改为对应月份文件名

其余算法、格式、公式全部复用。
